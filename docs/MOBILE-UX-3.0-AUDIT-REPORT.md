- وضوح العناصر
- تقليل الخطوات للوصول للخدمة

## 3. ملخص تنفيذي

### نقاط القوة الحالية

- وجود أساس متجاوب: `ervenow-responsive.css`، `responsive-audit-base.css`، `viewport-fit.js`
- قواعد لمس عامة: `--erw-touch-min: 44px`، `--erw-touch-primary: 48px`
- بنرات موحّدة 1920×730 مع `guest-offers-carousel`
- قالب أقسام بدأ بـ `section-hub.css` + `section-hub.js`
- صفحة التوصيل ومن الخريطة: نماذج كاملة مع مسار سلة

### نقاط الضعف الرئيسية

| # | المشكلة | التأثير |
|---|---------|---------|
| 1 | **هيدران مختلفان** (`lp-header` vs `dash-site-header`) | تجربة غير متسقة بين الرئيسية وباقي المنصة |
| 2 | **هيدر ضخم على الجوال** (~162–218px قبل المحتوى) | يستهلك 20–26% من الشاشة الأولى |
| 3 | **CSS مكرر** في مطاعم/متاجر/خدمات (~600 سطر inline لكل صفحة) | صيانة صعبة · اختلافات بصرية خفية |
| 4 | **Design tokens مجزّأة** (`--brown`, `--stores-*`, `--sn-*`, `--primary`) | ألوان وأحجام غير موحّدة |
| 5 | **أزرار غير موحّدة** (`.btn`, `.sn-hero__cta`, `.lp-btn-solid`, pills) | لا يشبه تطبيقاً واحداً |
| 6 | **مسار طويل للخدمة** على الجوال | 3–5 نقرات قبل الطلب الفعلي |
| 7 | **تحميل CSS غير مستخدم** (`index-header-banner.css` على صفحات guest-shell) | وزن إضافي بدون فائدة |

## 5. مشاكل حسب الفئة

### 5.1 التجاوب (Responsive)

- **نقطتا توقف غير موحّدة:** 640 vs 767 vs 768 vs 900 vs 1024 vs 1025
- **اقتراح توحيد:** 640 (جوال) · 1024 (تابلت) · 1025+ (كمبيوتر) — مطابق لـ `ervenow-responsive.css`
- **هيدر guest-shell:** 3 صفوف على الجوال · 2–3 على التابلت
- **لا overflow أفقي** في الصفحات المقاسة ✅

### 5.2 الأحجام (Sizing)

| العنصر | الحالي | المطلوب DS |
|--------|--------|------------|
| هيدر جوال | 162–218px | ≤120px (+ شريط سفلي اختياري) |
| بنر رئيسي | 289px جوال | 34–40vh clamp |
| بطاقة قسم | min-height غير موحّد | min 88px · padding موحّد |
| حقل بحث | 48px (hub) / 42px (forms) | 48px دائماً |
| خط جوال | 16px في بعض الحقول فقط | 16px minimum للحقول |

### 5.3 المسافات (Spacing)

**الوضع الحالي:** `clamp()` متفرق · `14px/20px` في `.layout` · `padding: 20px` في `.card`

**المطلوب:** مقياس 4pt:

```
--ds-space-1: 4px   --ds-space-2: 8px   --ds-space-3: 12px
--ds-space-4: 16px  --ds-space-5: 20px  --ds-space-6: 24px
--ds-space-8: 32px  --ds-space-10: 40px --ds-space-12: 48px
```

### 5.4 الأزرار (Buttons)

| النمط الحالي | المشكلة |
|--------------|---------|
| `.btn` | padding 10×18 · بدون min-height |
| `.lp-btn-solid` | gradient ذهبي |
| `.sn-hero__cta` | 40–48px مختلط |
| `.dash-site-header__btn` | gradient مختلف |
| Pills في التبويبات | جيدة بعد grid fix |

**أهداف لمس صغيرة (Before):** checkout (3) · delivery-map (1–2) · بعض صفحات الأقسام (1)

### 5.5 تجربة المستخدم (UX)

| مسار | خطوات اليوم | الهدف UX 3.0 |
|------|-------------|--------------|
| طلب من مطعم | رئيسية → مطاعم → فلتر → متجر → منتج → سلة → دفع | ≤4 نقرات للسلة |
| توصيل داخلي | توصيل → بطاقة → نموذج → سلة | 3 نقرات |
| من الخريطة | لوحة/رابط → خريطة → نقاط → سلة | 3 نقرات |
| زائر جديد | رئيسية طويلة → دخول منفصل | CTA واحد واضح |

## 6. Design System موحّد (مقترح UX 3.0)

### 6.1 هيكل الملفات المقترح

```
public/assets/design-system/
  tokens.css          ← ألوان · خط · مسافات · ظلال · z-index
  typography.css      ← عناوين · نص · عربي line-height ≥1.45
  buttons.css         ← primary · secondary · ghost · pill · icon
  cards.css           ← section · store · service · offer
  forms.css           ← input · select · textarea · error
  search.css          ← search bar · sticky variant
  filters.css         ← chips · tabs · sort bar
```

**التحميل:** `tokens.css` → باقي المكونات → `styles.css` (legacy shim تدريجي)

## 7. Mobile First — مبادئ التنفيذ

1. **اكتب CSS للجوال أولاً** — ثم `@media (min-width: 641px)` ثم `(min-width: 1025px)`
2. **محتوى أولاً** — الهيدر مضغوط · الإجراءات في متناول الإبهام
3. **شريط سفلي للزائر** (مقترح):

   | أيقونة | الوجهة |
   |--------|--------|
   | 🏠 | `/` |
   | 🔍 | `/restaurants` أو بحث موحّد |
   | 🛒 | `/checkout` |
   | 👤 | `/login` أو `/dashboard` |

4. **تقليل التكرار** — صفحة واحدة للزائر بدل رئيسية + لوحة مكررة
5. **Lazy load** للصور والبنرات
6. **لا Commit** إلا مع Before/After + شرح
