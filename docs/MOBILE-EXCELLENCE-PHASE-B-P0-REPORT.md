## ملخص تنفيذي

تم تنفيذ **P0 فقط** على الجوال (≤640px) دون المساس بتجربة الكمبيوتر. النموذج أصبح:

**بحث → تصنيفات (chips) → نتائج**

بدلاً من:

**Hero → شرح → فلاتر → ملاحظات → نتائج**

| الصفحة | أول نتيجة (قبل → بعد) | تمرير (قبل → بعد) | الكروم فوق النتائج |
|--------|------------------------|-------------------|---------------------|
| **المطاعم** | **803px → 183px** | **748px → 128px** | **1168px → 298px** |
| **المتاجر** | ~792px* → ~183px* | ~792px* → 0px† | **1156px → 282px** |
| **الخدمات** | **717px → ~179px**‡ | **661px → 0px** | **3322px → 282px** |
| **التوصيل** | **301px → 105px** | **245px → 49px** | **206px → 55px** |

\*تقدير عند وجود متاجر — نفس قالب المطاعم؛ بيئة الاختبار: 0 متاجر.  
†لا تمرير مطلوب عند ظهور أول بطاقة في نفس موضع المطاعم.  
‡منطقة النتائج/الحالة الفارغة؛ `#svcOrderPanel` المكرر مخفي على الجوال.

**الهدف (≤180px لأول مطعم):** **183px** — ضمن هامش **3px** من الهدف.

**زمن الوصول للخدمة (تقدير UX):**

| | قبل | بعد |
|---|-----|-----|
| مطاعم/متاجر | ~5–6 ث (تمرير + قراءة) | **~1.5–2 ث** (بطاقة ظاهرة فوراً) |
| خدمات | ~6–7 ث (لوحة 1059px + تمرير ~1495px) | **~2–3 ث** (مقدّم → sheet → إرسال) |
| توصيل | ~2–3 ث | **~1.5–2 ث** |

## ما تم تنفيذه (P0)

### 1. المطاعم والمتاجر — قالب Hub موحّد

على الجوال فقط (`html.erv-mobile-shell` + `body.stores-page`):

- إخفاء `.guest-section-hero`
- إخفاء `#hubSortBar` (فلاتر الترتيب الثقيل)
- إخفاء `#guestNote` وعناوين التصنيفات الطويلة
- إخفاء `#hubCountLine`
- **بحث sticky** تحت الهيدر (`top: 56px`)
- **تصنيفات chips** أفقية مضغوطة (48px ارتفاع)
- تقليل الحشو والفجوات لرفع `#container` للأعلى

### 2. الخدمات — مسار واحد

- إخفاء `#svcOrderPanel` من تدفق الصفحة على الجوال
- `mobile-services-flow.js`: نقرة مقدّم → **bottom sheet** بنموذج الطلب
- `section-hub-services.js`: `onOpenStore` يفتح الـ sheet بدلاً من الانتقال لـ `store.html` على الجوال
- داخل الـ sheet: إخفاء `svc-order-cards` المكررة والعنوان الفرعي

### 3. التوصيل — تقليم فقط

- إخفاء `.ds-crumb` و `.ds-quicklinks` و `.ds-section-block__hint`
- تقليل `padding` و `min-height` لـ `.ds-svc`
- **بدون** إعادة تصميم

### 4. Desktop — بدون تغيير

تحقق @1280px على `/restaurants`:

- Hero: ظاهر  
- `#hubSortBar`: `display: flex`  
- `#guestNote`: `display: block`  
- `erv-mobile-shell`: غير مفعّل
