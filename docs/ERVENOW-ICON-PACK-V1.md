# اعتماد رسمي — ERVENOW ICON PACK V1

## القرار

اعتبار هذه الحزمة هي الحزمة الرسمية الموحدة لجميع منتجات ERVENOW الحالية والمستقبلية.

يشمل:

- ERVENOW
- ERVENOW PAY
- KABSAR
- الهيف العقارية
- TAWTHEQ NEXUS (عند بدء التطوير)

## سياسة الاستخدام

1. يمنع إضافة أي إيموجي أو أيقونات جديدة داخل الواجهات إلا بعد اعتمادها.
2. جميع الصفحات الجديدة تستخدم هذه الحزمة فقط.
3. أي قسم جديد مستقبلاً يجب أن يحصل على رمز رسمي قبل استخدامه.
4. عند تطوير النسخة الاحترافية مستقبلاً يتم استبدال هذه الرموز بأيقونات SVG/3D بنفس المعاني والهوية البصرية.
