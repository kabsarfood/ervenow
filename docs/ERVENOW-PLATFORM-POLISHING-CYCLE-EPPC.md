# ERVENOW Platform Polishing Cycle (EPPC)

**الإصدار الرسمي:** 1.0  
**التاريخ:** 2026-07-01  
**النطاق:** جميع صفحات وبوابات ERVENOW  
**السياسة الرسمية:** [ERVENOW Engineering Policy (EPPC v1.0)](./ERVENOW-ENGINEERING-POLICY.md)

## الغرض

**EPPC** هي دورة العمل الرسمية لصقل واعتماد صفحات المنصة.  
تبدأ بالتقييم وتنتهي بالاعتماد النهائي — **في جولة صقل واحدة** دون تقسيم إلى مراحل منفصلة.

> الهدف: 🏆 **Production Quality Certified**  
> دون إضافة ميزات جديدة أو تغيير منطق العمل.

---

## قواعد عامة (ممنوع أثناء الدورة)

- إضافة ميزات جديدة
- تعديل Business Logic
- تعديل قاعدة البيانات
- تعديل APIs
- تغيير مسارات المستخدم الأساسية
- أي تعديل لا يخدم تجربة المستخدم مباشرة

## المسموح فقط

- تحسين الجودة · سهولة الاستخدام · الأداء · التجربة · الفخامة
- إزالة التشويش

## المرحلة 1 — Assessment

راجع الصفحة **بالكامل** قبل أي تعديل.

### معايير التقييم

| المعيار | الوصف |
|---------|--------|
| UX Ease | سهولة الوصول للإجراء الأساسي |
| Visual Appeal | جاذبية بصرية متناسقة |
| Premium Feel | إحساس بالفخامة والاحتراف |
| Human Experience | قابلية الاستخدام دون شرح |
| Performance | سرعة · CLS · LCP · DOM |
| Accessibility | تباين · تكبير · لوحة مفاتيح · SR |
| Desktop Experience | جودة @1280+ |
| Mobile Experience | جودة @390 |
| Eye Flow | مسار العين نحو الإجراء الأساسي |
| Focus | البطل البصري واضح |
| Noise | عناصر بلا قيمة |
| Cognitive Load | عدد القرارات فوق الطية |
| Content Simplicity | نصوص مختصرة · التصميم يشرح نفسه |
| Business Experience | الوصول للهدف التجاري ≤ 3 ث |

### المخرجات

1. جدول تقييم **A / B / C** لكل معيار
2. نقاط القوة والضعف مرتبة حسب الأولوية
3. تعريف **البطل البصري** و **Eye Flow** المستهدف للصفحة

**لا تعديلات في هذه المرحلة.**

---

## المرحلة 2 — Platform Polishing

نفّذ **جميع** التحسينات اللازمة في **جولة واحدة**.

### UX
- تبسيط الاستخدام · تقليل الخطوات · توضيح الإجراءات
- تحسين أماكن الأزرار · تجربة اللمس

### UI
- ألوان · ظلال · حواف · محاذاة · فراغات · أحجام · تناسق

### Premium Feel
- إزالة ما يضعف الفخامة
- أيقونات SVG موحّدة · هوية بصرية موحّدة
- إزالة إيموجي غير ضرورية · تفاصيل دقيقة

### Human Experience
راجع من منظور: كبير السن · مستخدم جديد · معتاد · خبير.

> هل يستطيع المستخدم استخدام الصفحة دون شرح؟

### Eye Flow & Focus
- العين تتحرك تلقائياً نحو الإجراء الأساسي
- البطل = بطل الصفحة — لا منافس بصري

### Noise Reduction
لكل عنصر: **ما القيمة التي يضيفها للمستخدم؟**  
إن لم توجد قيمة → احذف · انقل · ادمج.

### Content Simplicity
اختصر النصوص — كل كلمة غير ضرورية تُزال.

### Performance
- LCP · CLS · صور · خطوط · CSS · JS · DOM
- لا حجز مكان لمحتوى فارغ

### Accessibility
- تباين · تكبير · لوحة مفاتيح · Screen Reader
- أحجام لمس ≥ 44px · حالات focus واضحة

### Desktop & Mobile
- هاتف · لوحي · سطح مكتب — تجربة متسقة

### تسمية ملفات الصقل (اختياري)
```
public/assets/{page}-polish.css
```
أو ملفات متعددة عند الحاجة — يُوثّق في تقرير الاعتماد.

## المرحلة 3 — Validation

بعد الصقل، نفّذ الاختبارات التالية بقياس فعلي حيث أمكن:

| الاختبار | السؤال |
|----------|--------|
| **Eye Flow Test** | هل مسار العين يطابق التصميم المستهدف؟ |
| **Five Second Test** | ماذا تقدم الصفحة؟ ما أول إجراء؟ |
| **Silent Test** | 5 ثوانٍ بلا قراءة — أين الضغط؟ |
| **Memory Test** | ماذا يتذكر المستخدم بعد 10 ثوانٍ؟ |
| **Finger Distance Test** | مسافة الإبهام لأول إجراء (@390) |
| **Human Experience Test** | هل كل فئة مستخدمين تنجح دون شرح؟ |

### قياسات موصى بها
- Viewports: **390×844** (جوال) · **1280×800** (سطح مكتب)
- سكربتات: `scripts/p1c-home-validation.js` (قابل للتعميم لصفحات أخرى)
- لقطات: `docs/screenshots/{page}-validation/`

**لا تقدّر أرقاماً غير مؤكدة.**

## المرحلة 4 — القياسات (تقرير الجودة)

| المقياس | الوصف | هدف الاعتماد |
|---------|--------|--------------|
| **Focus Score** | وضوح البطل البصري | ≥ 8/10 |
| **Noise Score** | مستوى التشويش (أقل أفضل) | ≤ 5/10 |
| **Cognitive Load** | منخفض / متوسط / مرتفع | منخفض |
| **Comfort Score** | راحة بصرية وفراغات | ≥ 8/10 |
| **Confidence Score** | ثقة · SVG · روابط · فوتر | ≥ 8/10 |
| **Elegance Score** | ألوان · ظلال · حركات | ≥ 8/10 |
| **Business Score** | الوصول للهدف التجاري | ≥ 8/10 |
| **Smile Score** | خفة · راحة · وضوح | ≥ 8/10 |
| **Useful Words** | كلمات ذات قيمة فوق الطية | يُقاس |
| **User Success Metrics** | بطاقات في الطية · مسافة أول إجراء · إلخ | يُقاس |
| **Value Score** | نسبة قيمة / ضوضاء | عالي |
