# تنفيذ هجرة المالية — ERVENOW

> **ملف واحد جاهز:** `shared/RUN_ALL_FINANCE_MIGRATIONS.sql` (~56 KB)  
> **تنفيذ تلقائي:** `npm run migrate:finance` (يتطلب `SUPABASE_DB_URL` أو `SUPABASE_URL` + `SUPABASE_DB_PASSWORD` في `.env`)

## الطريقة الأسهل (بدون استخراج ملفات متعددة)

1. افتح الملف في المشروع:
   **`shared/RUN_ALL_FINANCE_MIGRATIONS.sql`**
   (إن لم يكن موجوداً شغّل: `npm run migrate:finance:bundle`)

2. اذهب إلى [Supabase](https://supabase.com) → مشروعك → **SQL Editor** → **New query**

3. في الملف: **Ctrl+A** ثم **Ctrl+C**

4. في SQL Editor: **Ctrl+V** ثم **Run** (أو Ctrl+Enter)

5. انتظر حتى يظهر **Success** (قد يستغرق 10–30 ثانية)

6. **Settings** → **API** → **Reload schema**

7. أعد تشغيل خادم Node على جهازك

---

## الطريقة التلقائية (إن عندك كلمة مرور قاعدة البيانات)

في ملف `.env` في جذر المشروع أضف **واحداً** من:

```env
SUPABASE_DB_URL=postgresql://postgres:كلمة_المرور@db.xxxxx.supabase.co:5432/postgres
```

أو:

```env
SUPABASE_URL=https://xxxxx.supabase.co
SUPABASE_DB_PASSWORD=كلمة_مرور_postgres
```

ثم من مجلد المشروع:

```bash
npm run migrate:finance
```

## بعد الهجرة — تسوية الطلبات القديمة

من حساب أدمن (Postman أو أداة API):

```http
POST https://عنوان-خادمك/api/admin/finance/reconcile-delivered
Authorization: Bearer توكن_الأدمن
Content-Type: application/json

{"limit": 50}
```

```sql
SELECT count(*) FROM ervenow_ledger_wallets;
SELECT count(*) FROM ervenow_ledger_transactions;
```

يجب ألا يظهر خطأ «relation does not exist».
